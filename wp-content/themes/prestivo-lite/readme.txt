Prestivo Lite is a free fashion WordPress block theme for building an online store for clothing, bags, shoes, and watches.

== Description ==

Prestivo Lite is an elegant free fashion eCommerce WordPress block theme for full site editing. This block-based theme is designed for online clothing and accessories stores that sell apparel, bags, shoes, watches, and jewelry. It is ideal for fashion boutiques, clothing labels, shoe stores, and store owners of all levels, from startups to established retailers. Prestivo Lite works perfectly with the eCommerce plugin "WooCommerce" and includes a complete shopping flow with Archive Product, Taxonomy Product Category, Single Product, Product Search Results, Cart, Checkout, and Order Confirmation templates. With the drag-and-drop interface, you can build your content using block patterns and adjust the color options to match your brand. There are 21 block patterns, 16 Templates, and 13 Template Parts available in this theme. Some of the block patterns are 404 Header, Blog Header, Header, Header Media, Footer, Footer Widgets, Post Header, Product FAQ, Search Header, Secure Transaction, Shop Header, Shopping Features, Sidebar Products, Taxonomy Product Header, and many more. All the block patterns, Templates, and Template Parts are fully responsive, fast loading, SEO friendly, translation ready, and highly customizable. Download Prestivo Lite today and build a professional-looking online fashion store.

== Installation ==

1. In your admin panel, go to Appearance -> Themes and click the 'Add New' button.
2. Type in Prestivo Lite in the search form and press the 'Enter' key on your keyboard.
3. Click on the 'Activate' button to use your new theme right away.
4. Go to https://catchthemes.com/themes/prestivo-lite/#theme-instructions/ for a guide on how to customize this theme.
5. Navigate to Appearance -> Editor in your admin panel and customize to taste.
