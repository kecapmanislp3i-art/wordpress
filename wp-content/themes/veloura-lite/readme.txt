== Description ==
Veloura Lite is a modern WordPress block theme for fashion boutiques, clothing stores, lifestyle brands, and online shops. It supports flexible content creation with standard WordPress blocks and includes customizable patterns for hero sections, featured collections, services, blog content, and calls to action. Veloura Lite is responsive, translation-ready, and designed to work across desktop, tablet, and mobile devices.
